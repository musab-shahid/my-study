# Curriculum status policy (pilot)

## Status meanings
| Status | Minimum evidence |
|--------|------------------|
| **deferred** | Intentionally out of scope or blocked |
| **mapped_partial** | Canonical leaf linked; instruction and/or practice incomplete or synthetic-only |
| **mapped** | Full instructional contract for the leaf: explanation, worked example, guided + independent practice, assessment with key/rubric, explicit limits |

## Not sufficient for `mapped`
- Registry row or crosswalk match alone
- Single worked number without independent practice
- Fixture pass without learner-facing tasks
- Real-world / operational validation (tracked separately)

## External validation
Record separately (docs or evidence notes). Never implied by `mapped`.
