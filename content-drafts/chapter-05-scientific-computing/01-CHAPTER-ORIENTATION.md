# Chapter 5 — Scientific Computing and Data Science
**Part I — Chapter orientation** | TOC edition 19 October 2026 | Chapter draft **v4** (all 12 units taught)

**Priority tags:** Core for 5.1–5.6 and 5.11; climate-track Core also includes 5.7; exit competencies in 5.8–5.11.

## Purpose
Develop the ability to design, implement, validate, explain, and reproduce scientific analyses on environmental, climatic, geospatial, and EO data. Not a generic coding course: mathematics, statistical judgement, and research software are first-class.

## Scope (twelve units)
| Unit | Title | Role |
|------|--------|------|
| 5.1 | Mathematical and physical foundations | Units, calculus, linear algebra, ODE intuition, probability |
| 5.2 | Python for scientific work | NumPy, Pandas, envs, time zones, formats |
| 5.3 | Exploration and visualisation | EDA, diagnostics, honest figures |
| 5.4 | Introductory statistics | Intervals, tests, correlation, simple regression |
| 5.5 | Data workflow and engineering basics | Pipelines, SQL, APIs, provenance |
| 5.6 | Intermediate inference and modelling | Dependence, uncertainty, out-of-sample evaluation |
| 5.7 | Time series analysis | Trend, seasonality, forecasting pitfalls |
| 5.8 | Multivariate analysis for climate and EO | PCA/EOF, clustering, field significance |
| 5.9 | Generalised, mixed, and Bayesian models | GLM, hierarchical, Bayesian checks |
| 5.10 | Causal inference for observational data | DAGs, designs, disciplined language |
| 5.11 | Research software practice | Git, tests, reproducibility |
| 5.12 | Multidimensional and pipeline computing | xarray, idempotent pipelines |

## Learner profile
BS Environmental Science + DataCamp ADS; Multan UHI, ERA5 monsoon, hotspot dashboard exposure. Prior exposure ≠ mastery — use the diagnostic.

## Competence ladder
L1 Recognise · L2 Apply with guidance · L3 Practise independently · L4 Extend and critique. Target L3 on core; evidence = public artefact (notebook, validation table, write-up).

## Diagnostic self-assessment (90–120 min)
1. Convert 28.5°C to K; state surface energy balance terms with units.
2. Eigenvalues of diag(2,3) as stretch factors.
3. Pandas: UTC hourly → PKT local-day maxima sketch.
4. View vs copy / chained assignment hazard.
5. Why n=10 000 pixels is not effective n for LST~NDVI.
6. Lag-1 autocorrelation and trend tests.
7. Five items in an ERA5 data manifest.
8. Distinguish confidence vs prediction interval.

Score ≤10 → study 5.1–5.2 systematically. Record gaps in a learning log.

## Study method
Topic-sized blocks; question→intuition→definition→assumptions→math→example→code→diagnostics→limits→practice. Distinguish LST, 2 m air temperature, and personal heat exposure in every heat example.
