## 5.2.1 Language core for scientific work

### 5.2.1.1 Style is a scientific issue
Prefer `lst_kelvin`, `precip_mm_day` over `x1`. Functions with explicit inputs/outputs. Docstrings that state units. Type hints where they clarify.

### 5.2.1.2 Structure

### 5.2.1.3 Errors and notebooks
Raise on impossible units or empty masks. Prefer `logging` over scattered prints. Notebooks for exploration; **Restart & Run All** before sharing; extract stable logic to `.py` modules.

## 5.2.2 NumPy

### 5.2.2.1 Arrays
```python
import numpy as np
temps_c = np.array([32.1, 33.0, 31.5], dtype=np.float64)
temps_k = temps_c + 273.15
```
Know `shape`, `dtype`. Vectorise over Python loops for large arrays.

### 5.2.2.2 Broadcasting
Misaligned broadcast is a silent bug when combining `(time,)` with `(lat, lon)`. **Print shapes before operating.**

### 5.2.2.3 NaN-safe reductions
`np.nanmean` ignores NaNs; `np.mean` propagates NaN. Fill values like −9999 treated as data destroy climatologies—mask with QA flags first.

### 5.2.2.4 Randomness
```python
rng = np.random.default_rng(seed=42)
```
Record seeds in the manifest when results depend on randomness.

### 5.2.2.5 Scale-factor helper
Do **not** hard-code operational product constants in library defaults. Pass scale and offset from the current product guide:

```python
def decode_st(raw: np.ndarray, scale: float, offset: float) -> np.ndarray:
    """Decode integer storage to kelvin using caller-supplied scale and offset.

    Look up scale/offset in the current product documentation (e.g. USGS Landsat
    Collection 2 ST) for the exact band and collection you are using.
    """
    return raw.astype(np.float64) * scale + offset
```

## 5.2.3 Pandas

### 5.2.3.1 Tables
One row = one observational unit (station-day, pixel-date—**state it**). Columns = variables with a data dictionary of units.

### 5.2.3.2 Dates and time zones (critical for Pakistan)
```python
import pandas as pd
df = pd.read_csv("station_hourly.csv", parse_dates=["time_utc"])
df["time_utc"] = pd.to_datetime(df["time_utc"], utc=True)
df["time_pkt"] = df["time_utc"].dt.tz_convert("Asia/Karachi")
df["local_date"] = df["time_pkt"].dt.date
daily_max = df.groupby("local_date")["t2m_c"].max()
```
PKT = UTC+5, no DST. UTC midnight boundaries bias local Tmax/Tmin and rain-day counts.

### 5.2.3.3 Missing data and resampling
Document whether missingness is seasonal. Use `min_periods` in rolling windows. Prefer explicit `NA` handling over silent fills.

### 5.2.3.4 Joins
Keys must identify the same entity. Check row counts before/after merges. Never merge on floating coordinates—use IDs or spatial joins (Subject 3).

### 5.2.3.5 View vs copy
Chained assignment may not modify the frame. Use `.loc`. Treat SettingWithCopy warnings as defects.
