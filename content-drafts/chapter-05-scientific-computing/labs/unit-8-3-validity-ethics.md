## Scenario

A team claims green roofs **cause** lower hospital admissions using parcel LST and clinic GPS without a pre-analysis plan.

## Task

Identify at least one issue in each of: construct, internal, external, statistical-conclusion validity; one leakage or causal overclaim; one sensitive-data concern; one integrity (selective reporting) issue.

## Assessment criteria

| Criterion | Pass |
|-----------|------|
| Four validity types | Each named with a concrete threat |
| Causal claim | Flagged without design justification |
| Sensitive location | Minimisation / re-identification noted |
| Integrity | Pre-analysis or selective reporting addressed |
| IRB | Student states checks ≠ institutional approval |

## Answer-key sketch

- Construct: LST ≠ core temperature / admissions mechanism  
- Internal: confounding by income, building stock  
- External: one belt ≠ whole city  
- Statistical conclusion: spatial dependence  
- Leakage: post-outcome filters  
- Ethics: clinic GPS minimisation  
- Integrity: no pre-analysis plan  
- **Not IRB approval**
