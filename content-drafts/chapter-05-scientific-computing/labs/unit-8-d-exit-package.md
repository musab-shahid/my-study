## Task

Produce one package object with four sections:

1. **design** — estimand, unit of analysis, data, validation plan, non-claim  
2. **methods** — data id/version, preprocessing, software, parameters  
3. **validity** — construct, internal, external, statistical-conclusion threats  
4. **reproducibility** — code availability, data availability (honest; no fake DOIs)

## Acceptance criteria

| Criterion | Pass |
|-----------|------|
| Estimand length | Specific quantity, not a topic word |
| Non-claim | Bounds causal or over-general claims |
| Methods stranger-test | Competent stranger could re-run from the text |
| Synthetic honesty | Teaching extracts not labelled as field validation |
| DOI honesty | Public DOI claimed only if identifier provided |

## Non-claims

Passing the fixture is **not** institutional ethics approval, peer review, or proof that Multan field conclusions are true.
